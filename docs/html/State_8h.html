Detailed Description

State pattern for the workflow instance lifecycle.

Pattern roles:

  • Context: WorkflowInstance
  • State: InstanceState
  • ConcreteState: CreatedState, RunningState, SuspendedState, CompletedState, CancelledState, FailedState

WorkflowInstance also takes part in the Observer pattern (as Subject) and the Memento pattern (as Originator).
