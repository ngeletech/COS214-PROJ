Detailed Description

Context. One running copy of a workflow.

Forwards lifecycle calls to its current InstanceState. It owns the current state and the root WorkGroup, and deletes both in its destructor.

Also acts as the Observer Subject (subscribe/publish) and the Memento Originator (saveSnapshot/restore).
