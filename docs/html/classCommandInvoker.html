Detailed Description

Manages command submission, execution and undo operations.

Maintains a queue of pending commands and a history of successfully executed commands. Before executing a command with a target instance, it asks the RollbackManager to save a snapshot of that instance.

During undo, the invoker retrieves the most recently executed command and asks the RollbackManager to restore the corresponding instance.

The invoker owns submitted command objects and deletes them when they are destroyed, discarded after execution failure or removed during undo.

Pattern role:

  • Invoker: Controls the execution of commands.
