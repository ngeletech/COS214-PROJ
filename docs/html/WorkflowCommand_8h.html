Detailed Description

Command pattern implementation for workflow operations.

Defines the abstract WorkflowCommand interface and its concrete implementations for performing operations on workflow instances.

Pattern roles:

  • Command: WorkflowCommand
  • ConcreteCommand: StartInstanceCommand, CancelInstanceCommand, ChangeDataCommand, ReassignItemCommand
  • Invoker: CommandInvoker

CommandInvoker manages command execution and history, while the RollbackManager uses the Memento pattern to restore previous workflow instance states.
