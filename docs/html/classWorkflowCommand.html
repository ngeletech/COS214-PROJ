Detailed Description

Abstract base class for workflow commands.

Defines the common interface for commands that perform operations on workflow instances. Stores a pointer to the target instance and requires concrete commands to implement the execute() operation.

The target pointer is non-owning. The command does not manage the lifetime of the workflow instance.

Pattern role:

  • Command: Defines the interface for executing operations.
