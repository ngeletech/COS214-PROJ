Detailed Description

Command for starting a new workflow instance.

Uses the WorkflowEngine to create a new instance from a workflow definition and its initial data.

This command has no target instance because it creates a new instance rather than operating on an existing one.

Pattern role:

  • ConcreteCommand: Implements the workflow-starting operation.
