Detailed Description

Facade. The single entry point for clients (the TUI).

Creates and wires the engine and its helpers, and hides them behind a few simple operations. Owns everything it creates, plus the participants and listeners passed to it.

Invalid requests throw: std::invalid_argument for unknown ids or names, std::logic_error for actions the instance's state refuses. The caller catches them.
