Detailed Description

Command for reassigning a workflow item to another participant.

Finds the specified work item, updates its assignee and adjusts the workload counters of the previous and new participants.

The target instance and new assignee are stored as non-owning pointers.

Pattern role:

  • ConcreteCommand: Implements the work-item reassignment operation.
